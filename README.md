# Prometeus — Floristry Website

A content-focused, responsive floristry website built with vanilla HTML5, CSS3 and JavaScript, with a strong emphasis on typography, accessibility and page performance.

🔗 **Live demo:** [blackaslife.github.io/Prometeus](https://blackaslife.github.io/Prometeus/)
📦 **Source code:** this repository

## Overview

Prometeus is a clean, content-first website design for a florist brand, prioritising readable typography, clear visual hierarchy and intuitive mobile navigation over heavy decoration.

## Features

- Typography-led, content-first design
- Accessibility-conscious layout and structure
- Optimised image assets for faster page loads
- Refined CSS selectors for improved rendering performance
- Fully responsive across desktop, tablet and mobile

## Built With

- **HTML5** — semantic, accessible markup
- **CSS3** — responsive layout, typography system
- **JavaScript (ES6+)** — light interactivity

## What I Learned

This project pushed me to think about performance from the image-asset stage onward — compressing and correctly sizing images before they ever reach the page, rather than trying to fix load times afterwards. It also reinforced how much typography and spacing decisions affect perceived quality, even on a fairly simple site.

## Getting Started

Clone the repository and open `index.html` directly in a browser.

```bash
git clone https://github.com/blackaslife/Prometeus.git
cd Prometeus
open index.html
```
